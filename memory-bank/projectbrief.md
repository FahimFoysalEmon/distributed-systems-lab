# Project brief

Hands-on **distributed-systems-lab**: implement and study backend / system-design concepts in a Spring Boot + Maven app.

## Goals

- Learn by building: consistent hashing, messaging (Kafka later), caching, rate limiting, idempotency, locks, etc.
- Keep each concept isolated under `lab.<topic>` with notes, code, and demos.
- Prefer understanding trade-offs over framework magic.

## Non-goals (for now)

- Production deployment
- Docker / Kafka until we deliberately add them
- Frontend UI

## Success criteria

- Clear package-per-topic structure
- Runnable demos / tests per topic
- Memory bank stays current so learning can continue across sessions
